# Jornada Oncológica

Este é o repositório do projeto **Jornada Oncológica**, uma aplicação web desenvolvida com tecnologias modernas para oferecer uma interface rica, responsiva e dinâmica. 

O design inicial do projeto está disponível no [Figma](https://www.figma.com/design/jwosexOSFyqx8TlEzdnKe6/Utilizar-arquivo-.md).

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

- **[React](https://react.dev/)** - Biblioteca JavaScript para construção de interfaces de usuário.
- **[Vite](https://vitejs.dev/)** - Ferramenta de build rápida e otimizada.
- **[Tailwind CSS v4](https://tailwindcss.com/)** - Framework de CSS utilitário para estilização rápida e responsiva.
- **[Radix UI](https://www.radix-ui.com/)** - Componentes primitivos não estilizados para construção do design system.
- **[Motion](https://motion.dev/)** - Para animações fluidas e interações ricas.
- **[Recharts](https://recharts.org/)** - Biblioteca de gráficos composta para React.
- **[React Router](https://reactrouter.com/)** - Navegação e roteamento.

## 📋 Pré-requisitos

Antes de começar, certifique-se de ter instalado em sua máquina:
- [Node.js](https://nodejs.org/) (recomendamos a versão LTS)
- Gerenciador de pacotes (`npm`, `yarn` ou `pnpm`)

## 🛠️ Como executar o projeto

Siga os passos abaixo para rodar o projeto localmente:

1. Clone o repositório (ou acesse a pasta raiz do projeto):
   ```bash
   cd Jornada_Oncologica
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Acesse a aplicação no seu navegador:
   O Vite normalmente iniciará o projeto em `http://localhost:5173`. Verifique o terminal para o endereço exato.

## 📦 Scripts Disponíveis

No diretório do projeto, você pode rodar os seguintes comandos:

- `npm run dev`: Roda o aplicativo em modo de desenvolvimento.
- `npm run build`: Cria a versão de produção otimizada na pasta `dist`.
