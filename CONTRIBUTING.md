# Como colaborar

Issue é uma tarefa ou problema registrado. Pull Request (PR) é uma proposta de incorporar uma alteração.

1. Abra uma Issue descrevendo o problema sem dados de pacientes.
2. Edite o documento pelo lápis no navegador. Ao salvar, escolha criar uma nova branch (linha de trabalho separada) e propor um PR.
3. Explique o que mudou e como conferir. Commit é o registro da alteração.
4. Peça revisão a outra pessoa. Após aprovação, alguém autorizado faz merge (incorpora a alteração) em main.

main é a versão integrada do projeto. Evite mudanças relevantes diretamente nela, mesmo quando o plano não permitir proteção automática.

Prefira Markdown para documentos vivos. Veja o [manual institucional](https://github.com/OceanBrasilia/handbook).
