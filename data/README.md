# Dados permitidos

GitHub NÃO é repositório de dados clínicos identificáveis, mesmo em projetos privados.

Aqui ficam schemas, exemplos sintéticos e dados anonimizados com autorização institucional. Não inclua prontuários, nomes de pacientes, CPF, identificadores ou exports hospitalares.

Comece criando um exemplo fictício em samples/ e documente sua origem e finalidade. Consulte [segurança](../SECURITY.md).
